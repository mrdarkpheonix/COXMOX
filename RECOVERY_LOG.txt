Recovery / clean setup
----------------------
1. Install Node.js LTS (npm is included).
2. From the project folder run:
       npm install
       npm run dev
3. To verify a production build:
       npm run build
4. To discard generated local outputs, remove only the project-local
   node_modules\ and dist\ directories, then run npm install again.

The npm install command will create package-lock.json with exact resolved
versions. Preserve package.json and package-lock.json together for repeatable
installs. No credentials or API keys are required by the current application.

Nearby event alert implementation
---------------------------------
The app now requests location permission when it starts; browsers still
require the user to grant permission, and the app cannot bypass that prompt.
For an authorized location it checks NASA EONET events against the selected
radius, shows a warning dialog, plays the matching local track for 20 seconds,
then speaks the summary. If browser autoplay is denied, the dialog offers
retry and immediate-speech actions. The event information is not an official
warning. Users can select a custom location by clicking the map or entering
latitude/longitude coordinates; GPS updates do not overwrite that choice
until the device-location control is selected.
